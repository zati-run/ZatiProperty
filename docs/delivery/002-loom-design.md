# Loom design guidance

## Decision

Distill the local UX-design canon, web-design craft guidance and visual taste notes
into portable NocoBase-specific instructions. Keep the original library untouched.
No wholesale copy or dependence on harness-specific design tools is introduced.
The canonical template is `.agents/skills/loom-init/assets/loom-design/`; the project
copy is `.agents/skills/loom-design/`. The initializer distributes that template.

Design decisions persist in `generation/design.md`. The short core routes to screen
patterns or rendered review only when needed. Native capability discovery, role
permissions, protected financial flows and Loom-only construction remain mandatory.
No live application generation or visual acceptance occurred in this preparation.

## Provenance

Adapted principles from the local library's `design/direction/ux-design/SKILL.md`
and `CANON.md`, `design/direction/web-design/SKILL.md` and `WEB.md`, and
`design/direction/ios-design/TASTE.md`: task orientation, hierarchy, progressive
disclosure, consistent rhythm and evidence-based critique. These source references
are provenance, not runtime dependencies or bundled third-party skill copies.

## Evidence boundary

Source review only for this change; no tests, builds or live MCP mutations run.
Prior initializer test results predate this change and do not qualify it. Actual
NocoBase appearance and interaction need a connected instance and browser review.

Independent source review approved the initializer and design package with a minor artifact-count documentation correction, now addressed. The design core is 554 words; references load only for the current screen/review stage. ZatiProperty also has a proposed `generation/design.md` baseline; its behavior and appearance remain unverified.
