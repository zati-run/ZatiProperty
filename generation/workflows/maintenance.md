# Maintenance assignment

Open request → inspect context → open linked work order → assign eligible vendor → save Quote → fresh read/reload confirmation. Server plugin enforces state/context/vendor guards regardless of UI. No vendor contact, notices, payments, screening or tax filing is sent. An editable no-code workflow is not the authority for invariant enforcement. Recurrence, emergency routing, quote comparisons, approvals, inspections and payment binding remain separately tracked in coverage.md.
